Fundamentos de Desenvolvimento Web

Hardware vs. Software

Hardware refere-se à parte física de um sistema computacional, ou seja, todos os componentes tangíveis que você pode tocar. Exemplos incluem o processador (CPU), a memória RAM, o disco rígido (HD/SSD), a placa-mãe, além de periféricos como monitor, teclado e mouse.

Software, por outro lado, representa a parte lógica do sistema. São os programas, dados, instruções e aplicativos que dizem ao hardware o que fazer. Exemplos incluem os sistemas operacionais (como Windows, Linux e macOS), navegadores de internet, jogos e os próprios códigos de desenvolvimento web.

Em suma: o hardware é o corpo e o software é a mente da computação.

Internet vs. Web

Embora usados frequentemente como sinônimos, eles não são a mesma coisa:

A Internet é a infraestrutura global de rede. Ela conecta fisicamente bilhões de computadores, servidores, cabos submarinos e satélites ao redor do mundo, permitindo a troca de dados em geral.

A Web (World Wide Web) é um serviço que funciona no topo da Internet. Ela é o sistema de páginas interconectadas, documentos e mídias que acessamos utilizando navegadores através do protocolo HTTP/HTTPS. A Internet hospeda a Web, assim como hospeda outros serviços como e-mails, aplicativos de mensagens e redes de jogos online.

Conceitos de Rede e Infraestrutura

  • Cliente: É o dispositivo ou aplicação (como o navegador no seu computador ou celular) que faz requisições para acessar um serviço ou página web.
  • Servidor: É um computador de alta performance configurado para armazenar arquivos e "servir" essas páginas ou dados sempre que um cliente faz uma requisição.
  • IP (Internet Protocol): É o endereço numérico exclusivo que identifica cada dispositivo conectado à rede, permitindo que eles se localizem e conversem entre si.
  • DNS (Domain Name System): Funciona como a "lista telefônica" da internet. Ele traduz nomes de domínios amigáveis (como exemplo.com) nos endereços IP reais onde os sites estão hospedados.
  • Domínio: É o nome amigável e legível utilizado para acessar um site na barra de endereços (ex: google.com), criado para que as pessoas não precisem memorizar sequências complexas de números (IP).
  • Hospedagem: É o serviço de aluguel de espaço em um servidor para armazenar todos os arquivos, imagens e códigos que compõem o seu site, mantendo-o disponível na internet 24 horas por dia.

A Tríade da Web: HTML, CSS e JavaScript

Para construir a interface de um site que roda diretamente no navegador do usuário, utilizamos três tecnologias fundamentais:

HTML (HyperText Markup Language): É a linguagem de marcação que define a estrutura e o conteúdo da página. É através do HTML que inserimos os textos, títulos, imagens, links e formulários.

CSS (Cascading Style Sheets): É a linguagem de estilos usada para definir a aparência visual da página. O CSS controla as cores, fontes, espaçamentos, alinhamentos e a responsividade (adaptação a telas de celulares e monitores).

JavaScript: É a linguagem de programação que adiciona dinamismo e interatividade ao site. Com o JavaScript, podemos criar animações, validar formulários antes do envio, atualizar conteúdos sem recarregar a página e reagir às ações do usuário em tempo real.

Marcos da Evolução Histórica da Computação e da Web

Abaixo estão listados cinco marcos fundamentais que moldaram o desenvolvimento tecnológico atual:

  • Criação da ARPANET (1969): O projeto militar americano que interconectou computadores de universidades e se tornou a base conceitual e tecnológica da Internet como conhecemos hoje.
  • Invenção da World Wide Web por Tim Berners-Lee (1989): A criação do sistema de informações que permitiu a navegação por páginas e hipertextos, além da criação do primeiro navegador e servidor web no CERN.
  • Lançamento do Navegador Mosaic (1993): O primeiro navegador web popular a exibir imagens junto com textos na mesma tela, popularizando o acesso à rede para o público geral.
  • Criação do JavaScript (1995): Desenvolvido por Brendan Eich na Netscape, o nascimento da linguagem revolucionou a web ao permitir que as páginas deixassem de ser estáticas e passassem a ser interativas.
  • Lançamento do iPhone e o início da Web Móvel (2007): A popularização dos smartphones transformou radicalmente o desenvolvimento web, exigindo que sites fossem otimizados para telas menores através do design responsivo.
