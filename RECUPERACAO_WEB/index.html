  • RESPOSTA DA PÁGINA
  • 1. Explique o papel de cliente e servidor.

    • R: O cliente é quem vai solicitar o pedido de um dado, pacote de informação, ao servidor que é quem vai recebr esse pedido e deve responder ao cliente.

  • 2. Defina IP em uma frase.

    • R: Endereço/ números usados para identificação da máquina.

  • 3. Explique por que o DNS facilita nossa navegação.

    • R: Ao invés de precisar decorar números como o do endereço do IP, o DNS permite que você possa buscá-los através de nomes.

  • 4. Diferencie domínio e hospedagem.

    • R: Domínio é nome do site na web já o servidor é o local que os arquivos desse site ficam disponíveis.

  • 5. Diferencie HTTP e HTTPS conforme o conteúdo estudado.

    • R: HTTP faz a comunicação entre a web e a rede, já o HTTPS faz o mesmo porém utiliza criptografia em sua proteção.

  • Checkpoint: ao digitar um endereço no navegador, quais elementos do conteúdo estudado podem participar até a página aparecer na tela?

    • R: O DNS que é o nome, o protocolo https, o servidor da web, o html, o css e o javascript.
