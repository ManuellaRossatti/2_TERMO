Checkpoint: explique a diferença entre tag, atributo, seletor, propriedade e valor:

R: Tag é a marcação que define o início e o fim de um elemento HTML, como "<p>" para parágrafos ou h1 para títulos. Atributo é uma característica adicional que fornece informações sobre a tag, como 'class' ou 'id'. Seletor é usado em CSS para selecionar elementos HTML específicos para aplicar estilos. Propriedade é uma característica visual que você deseja alterar, como 'color' ou 'font-size'. Valor é o valor atribuído a uma propriedade, como 'red' para a cor ou '16px' para o tamanho da fonte.
