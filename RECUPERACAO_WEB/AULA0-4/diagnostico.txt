Checkpoint: explique a diferença entre hardware e software e cite dois exemplos de cada um
relacionados à aula. 
Hardware é o nome dado a todos os componentes físicos da máquina como por exemplo o monitor, o porcessador e a placa mãe.
Software é o nome dado a todos os programas que são utilizados pelo usuário através dos hardwares. Exmplos de software são o sistema operacional Windows e seu navegador Edge.
