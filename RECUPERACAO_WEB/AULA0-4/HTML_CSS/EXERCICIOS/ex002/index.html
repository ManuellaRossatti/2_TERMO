Minha revisão de HTML

Durante a revisão de HTML, aprendi sobre tags e estrutura básica. Um exemplo é a tag <h1> para definir títulos, e a tag <p> para definir parágrafos, e a tag <br> para definir quebras de linha.
Além disso, também aprendi sobre atributos e como utilizá-los para personalizar os elementos. Para exemplos, podemos usar o atributo "class" para aplicar estilos CSS a um elemento.

HTML (HyperText Markup Language): É a linguagem de marcação que define a estrutura e o conteúdo da página.
É através do HTML que inserimos os textos, títulos, imagens, links e formulários.

CSS (Cascading Style Sheets): É a linguagem de estilos usada para definir a aparência visual da página.
O CSS controla as cores, fontes, espaçamentos, alinhamentos e a responsividade (adaptação a telas de celulares e monitores).

JavaScript: É a linguagem de programação que adiciona dinamismo e interatividade ao site.
Com o JavaScript, podemos criar animações, validar formulários antes do envio, atualizar conteúdos sem recarregar a página e reagir às ações do usuário em tempo real.

Aprendi também sobre entidades HTML e como utilizá-las para representar caracteres especiais. Por exemplo, a entidade &nbsp; representa um espaço não quebrável:  
a entidade &copy; representa o símbolo de copyright: ©, a entidade &reg; representa o símbolo de marca registrada: ®,
e a entidade &trade; representa o símbolo de marca comercial: ™.
