Antigamente, os sistemas operacionais mais antigos (como o MS-DOS e versões primordiais do Windows)
exigiam que as extensões de arquivos tivessem no máximo três letras.
Por causa disso, a extensão .jpeg foi abreviada para .jpg.
em cima temos uma imagem no formato .jpg e a baixo temos uma imagem .jpeg.

Aqui temos uma imagem no formato .png,
que é um formato de imagem que suporta transparência e compressão sem perda de qualidade.
